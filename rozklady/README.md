# Rozkłady jazdy gmin powiatu wołomińskiego

Pliki `<gmina>.json` czyta shortcode `[zycie_rozklady gmina="..."]` (wtyczka zycie-dziki na zyciepw.pl).
Stan danych: 15.11.2026.

Źródła: ZTM Warszawa (wtp.waw.pl, rozkłady przystankowe), Koleje Mazowieckie (PDF R6, R61/62, R92),
Starostwo Powiatowe w Wołominie (8 linii powiatowych, PDF), Gmina Radzymin (linie R, PDF),
Miasto Ząbki (linie Ząbki-1…5W, PDF), współrzędne przystanków: OpenStreetMap.

Odświeżanie: skrypty w `_skrypty/` (parsery PDF + `gminy_build.py`).
Rozkład KM ważny do 12.12.2026 – po zmianie wgrać nowe PDF-y.
